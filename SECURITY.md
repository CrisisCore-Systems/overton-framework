# Security policy

## Reporting a vulnerability

If you believe you have found a security issue in this repository or in any reference implementations linked from it, please report it privately.

- Email: crisiscore.systems@proton.me

When reporting, please include:

- A clear description of the issue and impact
- Reproduction steps (as safe as possible)
- Affected file(s) / commit(s)
- Any suggested mitigations

## Coercion- and safety-sensitive issues

If the issue relates to coercion/duress protections, user safety, or could materially increase risk to people in vulnerability states, **do not** open a public GitHub issue. Use the email above so mitigation can be coordinated before details are published.

## Scope notes

- This repository contains a scope-locked Canon and a fast-moving Companion; it is not a certification.
- Please avoid sending real user data, medical records, or other sensitive material in reports. Use synthetic or redacted examples whenever possible.
