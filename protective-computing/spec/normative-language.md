# Normative Language

## Status
This document is **normative** for Protective Computing Core v1.0.

## Interpretation
The key words **MUST**, **MUST NOT**, **REQUIRED**, **SHALL**, **SHALL NOT**, **SHOULD**, **SHOULD NOT**, **RECOMMENDED**, **MAY**, and **OPTIONAL** in this repository are to be interpreted as described in RFC 2119 and RFC 8174 **only when** they appear in all capitals.

## Scope
Normative statements define conformance requirements for systems that claim conformance to **Protective Computing Core v1.0**.

## Document Conventions
- **Normative** sections contain requirements.
- **Informative** sections provide rationale, examples, and non-binding guidance.
- The term **system** refers to the complete socio-technical system in scope (client, server, storage, operations, and user-facing flows).

## Requirement Identifiers
Normative requirements in the Core Specification are uniquely identified as `PC-REQ-n`.
