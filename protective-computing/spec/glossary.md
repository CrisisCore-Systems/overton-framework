# Glossary

## Status
This document is **normative** for terms used by Protective Computing Core v1.0.

## Terms

### Stability Assumption
The implicit assumption that users operate with (a) reliable connectivity, (b) sufficient cognitive capacity for complex flows, (c) environmental safety, and (d) institutional trust.

### Stability Bias
A systematic tendency in system design and operation to optimize for stable conditions and to treat instability as an exceptional failure case.

### Vulnerability State
A condition in which user agency is degraded by one or more of: connectivity loss, cognitive overload, environmental instability, institutional latency, or coercive access.

### Local Authority
The property that the user can access and control essential utility and essential data **without** dependence on remote infrastructure or remote administrative discretion.

### Exposure Surface
The set of data flows, metadata emissions, interfaces, logs, and dependencies through which sensitive information can be disclosed or inferred.

### Reversibility
The property that high-impact state transitions (including deletion, access revocation, or irreversible permissions) remain recoverable within a bounded restoration window, especially during Vulnerability States.

### Protective Legitimacy
The degree to which a system’s architecture and operational behavior preserves user agency, safety, and dignity under Vulnerability States.
